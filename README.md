# Texto vivo com BBCode

Projeto da aula extra 01 da [CiaNCI](https://www.youtube.com/@CiaNCIStudio): caixa de diálogo com `RichTextLabel`.

- **Godot:** 4.7 (GDScript)
- **Como rodar:** importe `project.godot` e rode o projeto.
- `main.tscn`: a caixa de diálogo. Clique em "sertão".
- `nome.tscn`: texto do jogador sem e com proteção. Rode com "Run Current Scene".
